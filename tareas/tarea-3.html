  5. [10 puntos] Realice la descomposición de Goodman-Bacon (2021). Construya un gráfico donde muestre en el eje \(x\) el peso otorgado a cada comparación 2x2 y en el eje \(y\) el efecto estimado correspondiente a cada comparación. Interprete el gráfico obtenido.

    Sugerencia: use la función bacon_rapido en lugar de bacon(). La función bacon() del paquete bacondecomp estima cada comparación 2x2 con lm y dummies de municipio, lo cual es muy lento con más de 5,000 municipios y muchas comparaciones. Se prefiere bacon_rapido porque estima cada comparación con felm, que absorbe los efectos fijos sin construir las dummies. Los grupos y los pesos se siguen definiendo con las funciones internas de bacondecomp, así que la descomposición es la misma.

    bacon_rapido <- function(formula, data, id_var, time_var) {
  vars <- bacondecomp:::unpack_variable_names(formula(terms(formula, data = data)))
  data <- bacondecomp:::rename_vars(data, id_var, time_var,
                                    vars$outcome_var, vars$treated_var)
  calc <- bacondecomp:::create_treatment_groups(data, vars$control_vars,
                                                return_merged_df = TRUE)
  two_by_twos <- calc$two_by_twos
  data <- calc$data
  for (i in seq_len(nrow(two_by_twos))) {
    k <- two_by_twos[i, "treated"]
    l <- two_by_twos[i, "untreated"]
    data1 <- bacondecomp:::subset_data(data, k, l)
    two_by_twos[i, "weight"]   <- bacondecomp:::calculate_weights(data1, k, l)
    two_by_twos[i, "estimate"] <- coef(felm(outcome ~ treated | factor(id) + factor(time),
                                            data = data1))["treated"]
  }
  bacondecomp:::scale_weights(two_by_twos)
}
