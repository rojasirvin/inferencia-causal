Pregunta 1

En Crépon et al. (2015)1 se estudia una intervención en Marruecos en la que se analiza el efecto de la adopción de microfinanzas, a través de un experimento de campo. En 81 de 162 localidades estudiadas se introdujo aleatoriamente una empresa de microfinanzas. Para seleccionar las localidades de tratamiento, primero se emparejaron localidades de acuerdo a características observables y, para cada pareja se asignó una a tratamiento y otra a control. La variable que identifica a las parejas es paire. La base de datos crepon_morocco_balance.csv contiene los datos de este estudio usados para mostrar la integridad del diseño. La variable treatment es la variable de asignación aleatoria, mientras que la variable client es la variable de adopción.

En esta pregunta pondremos en práctica lo aprendido sobre múltiples hipótesis. En el archivo datos_indices.csv se presentan los datos de una intervención a 2,457 individuos.   1. [5 puntos] Para cada variable, estime el impacto del tratamiento con una regresión del tipo:

  5. [5 puntos] Construya ahora el índice de Kling, Liebman y Katz, \(z_i\), para cada una de las seis familias. Luego estime el efecto causal para cada una de ellas:

    \[z_{i}^k=\tau_0^k+\tau_1^k T_i + \Omega^k X_i + \nu_i^k\] Genere un cuadro de resumen donde muestre el efecto causal para cada uno de los índices de las seis familias. ¿Qué se concluye para cada una?

    Seguimos los cuatro pasos del procedimiento descrito en clase. El segundo es fácil de olvidar y es que tenemos que reconocer hay variables donde mayor es peor (por ejemplo dias_sin_comida o indice_estres). Como vimos en clase, antes de estandarizar debemos invertirles el signo. Si no se hace, esas variables entran al promedio restando y el índice queda mal construido. La columna orientacion del diccionario indica cuáles son dichas variables:

    familias <- unique(dicc$familia)

for (f in familias)
{
  vars <- dicc |> dplyr::filter(familia == f)

  Z <- matrix(NA, nrow(datos), nrow(vars))

  for (j in 1:nrow(vars))
  {
    #Paso 2: orientar de modo que mayor siempre sea mejor
    x <- datos[[vars$variable[j]]] *
      ifelse(grepl("PEOR", vars$orientacion[j]), -1, 1)

    #Paso 3: estandarizar con la media y la de del grupo de control
    Z[, j] <- (x - mean(x[control], na.rm = TRUE)) / sd(x[control], na.rm = TRUE)
  }

  #Paso 4: promediar los z-scores disponibles de cada individuo
  z_barra <- rowMeans(Z, na.rm = TRUE)
  z_barra[rowSums(!is.na(Z)) == 0] <- NA

  #Reestandarizar el promedio contra el grupo de control
  datos[[paste0("z_", f)]] <-
    (z_barra - mean(z_barra[control], na.rm = TRUE)) /
      sd(z_barra[control], na.rm = TRUE)
}

    • Consumo: \(\hat{\tau}_1 = 0.437\) (\(p < .01\)). El efecto más grande del estudio y el más robusto. Esto ya era evidente variable por variable.
    • Ingresos y trabajo: \(\hat{\tau}_1 = 0.277\) (\(p < .01\)). Efecto grande en magnitud y estadísticamente significativo.

Conviene por eso reportar el índice junto con los resultados variable por variable, no sólo el índice.

    Conclusión general. Los índices no son un sustituto de las correcciones por múltiples hipótesis, sino una estrategia complementaria con un balance distinto. Reducen el número de hipótesis de 49 a seis, lo que hace la corrección mucho menos costosa, y ganan potencia al agregar señales débiles y dispersas (como en el caso de la salud mental). El precio es que pierden resolución, es decir, no dicen qué variable se movió y pueden ocultar un efecto concentrado en una sola (como pasó con educación).

Esta corrección consiste en multiplicar la matriz de sándwich agrupada CR0 por \(\frac{G(N-1)}{(G-1)(N-p)}\), donde \(G\) es el número de grupos, \(N\) es el número total de observaciones y \(p\) es el número de regresores.↩︎
